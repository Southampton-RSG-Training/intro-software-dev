:::::::::::::::::::::::::::::::::::::: questions

- How can I keep track of changes to my research code and documents?
- How can Git help me recover from mistakes and experiment with confidence?
- How can I collaborate effectively with others using version control?

::::::::::::::::::::::::::::::::::::::::::::::::

::::::::::::::::::::::::::::::::::::: objectives

- Explain the purpose and benefits of version control in research.
- Create and manage a local Git repository.
- Record changes using meaningful commits.
- Inspect the history of a project and compare previous versions.
- Restore files or earlier versions of a project when needed.
- Work with branches to develop and test changes independently.
