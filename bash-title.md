:::::::::::::::::::::::::::::::::::::: questions

- How can I use the command line to work more efficiently with files and folders?
- How can I automate repetitive tasks instead of performing them manually?
- How can I combine simple command-line tools to process research data quickly and reliably?
::::::::::::::::::::::::::::::::::::::::::::::::

::::::::::::::::::::::::::::::::::::: objectives

- Navigate the file system and manage files and directories using the Bash shell.
- Use command-line tools to inspect, manipulate and search files.
- Redirect input and output to create efficient command-line workflows.
- Combine commands using pipes to perform more complex operations.
- Write loops to automate repetitive tasks across multiple files.
- Use pattern matching and search tools to locate files and extract information.
