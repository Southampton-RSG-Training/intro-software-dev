## Sandy the STEM Student

Sandy has just started a PhD in Bioinformatics after completing a Computer Science degree. She is comfortable writing Python from undergraduate coursework but has never contributed to a shared codebase or worked on a research project that will evolve over several years. Her Centre for Doctoral Training recommended this course so she can establish good habits from the outset. Sandy wants to learn how to automate repetitive tasks with the Bash shell, use Git to keep her work safe, and write Python code that will still be understandable at the end of her PhD.

## Jay the Geographer

Jay is in the second year of a PhD in Geography, analysing satellite imagery and environmental data. He taught himself enough Python to get started but now has dozens of scripts with names like `analysis_final_v3.py`, making it difficult to remember which version produced which results. Jay hopes the course will help him organise his work, automate repetitive processing of data files, and use Git to make his research reproducible.

## Priya the Postdoctoral Researcher

Priya is a postdoctoral researcher in Psychology, working with colleagues across three universities. She regularly writes analysis code that is shared with collaborators, but much of it has grown organically over several projects. Priya wants to improve how she manages changes, documents her code, and collaborates using Git.

## Alex the Experimental Researcher

Alex is a research fellow in Mechanical Engineering who works with laboratory instruments that generate hundreds of data files every week. He currently spends hours renaming files, running the same analyses repeatedly, and producing figures for colleagues. Alex enrolled on the course to learn how to automate these tasks using the Bash shell and Python, freeing up more time for interpreting results rather than preparing them.
